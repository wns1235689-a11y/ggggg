# 게이트 C — 파일럿 프로토콜 (실행용 사본)

> **마스터 문서**: `게이트C_설문설계.md` v1.4 §5. 내용 충돌 시 마스터가 우선한다. 이 사본은 파일럿 실행 시 단독 참조용이다.

## 5. 파일럿 프로토콜 (본 배포 전 필수 관문)

**목적** — 본 배포 전에 측정 도구 자체의 결함을 탐지한다. 파일럿이 검증하는 것은 응답 *내용*이 아니라 **설문지와 파이프라인**이다: 문항이 의도대로 읽히는가, 3분 안에 끝나는가, 응답이 §3 규칙으로 계산 가능한 형태로 기록되는가.

**조건(사전)**

| 항목 | 내용 |
|---|---|
| 대상·인원 | 지인 학회 단톡방 5~10명 (아는 사이 — 블라인드 불필요, 점검 목적 공개). **모바일 응답자 과반 포함**(그리드 오독 리스크의 주 무대가 좁은 화면) |
| 발송 문구 | §1 파일럿 발송 키트(피드백 3종 요청 포함) |
| 발송 전 상태 | 폼이 §2와 일치 + §6 체크리스트의 설정 항목(셔플·필수·안내문) 완료 |
| 데이터 지위 | 본 분석 전량 제외(§3-14) — 발송·회수 시각 기록 |

**절차(탐색 과정)**

1. **발송** — §1 키트 문구로 발송, 발송 시각 기록.
2. **회수** — 응답 5명 이상 + 피드백 3종(소요 시간·오해 문항·가성비 인지) 회수. 목표 48시간.
3. **점검 — 5개 탐색 항목**
   - (a) **소요 시간**: 자가 보고 수집(Forms는 소요 시간을 기록하지 않음) — 중앙값 기준.
   - (b) **문항 이해**: 피드백 ②에 더해 응답 데이터의 이상 패턴을 교차 — B4 오답, B2 같은 행 중복 선택, D1 비단조 발생률이 파일럿에서 비정상적으로 높으면 그 자체가 문항 결함 신호다. 이상 패턴은 기기(피드백 ④)와 교차해 모바일 특이 결함인지 확인한다.
   - (c) **이탈**: "하다 말았다" 여부를 단톡방에서 확인(Forms는 부분 응답을 저장하지 않아 자가 보고로만 가능).
   - (d) **인지 인터뷰**: '외식 대비 가성비'의 의미 회수 → §4 기대 가성비 해석에 반영. **합격 조건이 아니라 해석 자료** — 의미가 갈려도 불합격 사유가 아니다.
   - (e) **파이프라인 드라이런**: 응답 시트에서 §3 규칙이 실제로 계산되는지 파일럿 데이터로 시범 실행 — 1차 컷(규칙 1), B2 계열 집계(규칙 11), D1 곡선·비단조 플래그(규칙 15), prefill 기록(F1) 확인.
4. **판정** — 합격 기준(전부 충족): **소요 중앙값 ≤3분 · 문항 오해 0건 · 중도 이탈 0건 · 드라이런 통과.**
5. **분기**
   - **합격** → 본 배포 전환(아래).
   - **불합격** → 결함을 두 급으로 분류해 처리한다.
     - (가) **문구 수정**(의미 불변 — 오탈자·표현 다듬기): 즉시 수정 후 본 배포 가능, 재파일럿 불요.
     - (나) **측정 변경**(문항·선택지·규칙·순서 변경): 수정 → 설계서 버전 갱신·변경 이력 기록 → **재파일럿**(3~5명으로 축소 가능) → 재판정.
   - 수정 권한 경계: §3 잠금은 "본 수집 시작 전"까지다 — 파일럿 단계의 수정은 허용되나, 모든 수정을 이력에 남긴다(사전등록 정직성).

**본 배포 전환 조건(전부 충족 후 발송)** — ① 파일럿 합격 판정 ② 폼 최종본 고정(이후 무수정) ③ prefill 링크 3종 생성 ④ 본 배포 시작 시각 기록(§3-14 경계) ⑤ §3 잠금 선언.

**본조사 절차 개요(전환 후)** — ① 3채널 발송(§1) → ② 마감 조건 감시(§3-6, 중간 결과 엿보기 금지) → ③ 마감 → ④ 정리(파일럿 제외 → B4 제외 → 중복 필터 → 1차 컷) → ⑤ 집계(§3 규칙 순서대로) → ⑥ E §9.4 기록(파일럿 결과 요약 포함) → ⑦ 경품 추첨·발송, F2 연락처 폐기.
