# 게이트 C — 설문 설계서 (v1.4, 2026-07-12 확정)

> **위치 선언(사전 명시).** 이 설문은 **탐색 전용**이다 — 기제(왜 T2가 이겼나)·가격 수용성·저커밋 해석·메시지 선호를 진술 차원에서 탐색한다. 게이트 B의 행동 판정(H2: T2 ≥ T1, 방향 판정)은 **이 설문의 어떤 결과로도 바뀌지 않는다**(약한 신호는 강한 신호를 기각할 수 없다 — 문서 B §6). 결과는 문서 E에 §9.4로 기록한다.
>
> **이력** — v1.0(초안) → v1.1(7렌즈 검토 16건) → **v1.2**: 파일럿 전 정밀 교정 12건 — 사용자 지적 3건(①B2 '가성비'=기대 가성비 해석 명기+인지 인터뷰, ②B2 '이유 없음' 안내문, ③D1 비단조 처리 규칙) + 자체 발견 9건(A2 MECE 보강, B2·A2 집계 정의 잠금, B3 '양' 추가, C1⑤ 처리, 파일럿 응답 제외, 탐색 교차 일반화, 체크리스트 공백 3건, 성인 대상 명시, 파일럿 키트 정식화) → **v1.3**: **§5 파일럿 프로토콜 신설** — §1·§3-14·체크리스트에 조각나 있던 파일럿 조항을 조건·탐색 절차·합격 판정·불합격 분기(재파일럿 루프)·본 배포 전환 조건·본조사 절차 개요로 통합 → **v1.4**: 파일럿 전 **합성 시뮬레이션**(가상 응답 8건 — 실제 파일럿 아님, §5 판정 불성립·데이터 지위는 설계 리스크 탐지용)이 지적한 2건을 **방법론적 독립 근거로 채택** — ① D1 행 셔플 OFF·오름차순 고정(측정 변경: 가격은 순서형 항목이라 셔플이 오독발 비단조를 만들어 §3-15 플래그를 오염; 균일 제시 앵커는 상대 비교 유지), ② B2 그리드 선택 방식 안내 보강(문구 수정). 파일럿 키트에 기기 확인 추가. **실제 파일럿은 v1.4 기준으로 최초 실시.**

### 섹션 2 — 사전 태도 (컨셉 노출 전 · unprimed)
- **A1★** 팟타이(태국식 볶음쌀국수)를 먹어본 경험은? — ① 먹어봤고 좋아한다 ② 먹어봤고 보통이다 ③ 먹어봤지만 별로였다 ④ 먹어본 적 없다
- **A2★ ⓢ** 동남아 음식(태국·베트남 등)을 **지금보다 자주 먹지 않는 가장 큰 이유**는? — ① 고수 등 향신료 향이 부담스러워서 ② 피시소스 등 낯선 소스·재료가 부담스러워서 ③ 먹을 기회나 파는 곳이 마땅치 않아서 ④ 가격이 부담스러워서 ⑤ **동남아 음식 자체를 즐기지 않아서** ⑥ 지금도 거리낌 없이 잘 먹는다
  - *의도: A 시나리오(향 기피 ①②)와 B 시나리오(접근성 ③)의 유병률을 **컨셉 노출 전·비구매자 포함 표본**에서 동시 측정 — 게이트 A 리뷰 코퍼스의 선택 편향(기구매자만)을 보완하는 핵심 문항. ⑤는 향과 무관한 단순 비선호의 배출구 — 없으면 그들이 ①②를 대충 골라 A 유병률이 과대측정된다(v1.2 MECE 보강). 집계 정의는 §3-12.*

### 섹션 3 — 컨셉 반응 (컨셉 카드 노출 · **가격 없음**)

> **[신제품 컨셉]** 태국 볶음쌀국수 '팟타이'를 한국 재료로 재해석한 냉동 간편식입니다. 새콤한 맛을 내는 타마린드 대신 **매실청**을 써서, 고수·피시소스 같은 향 부담을 덜었습니다. 냉동 쌀면 + 매실청 소스 + 국산 새우·숙주·부추 구성, 1인분(300g), 5분 완조리.

*(동결된 제품 사실만 사용. 브랜드·제품명·가격 비노출 — 가격은 섹션 5에서 첫 노출.)*

- **B1★** 이 제품의 첫인상은? — 선형배율 1~5 (1=전혀 안 끌린다, 5=매우 끌린다)
- **B2★** 이 제품을 **사고 싶게 만드는 이유**는? 1순위와 2순위를 하나씩 골라주세요. **1순위 열에서 하나, 2순위 열에서 하나를 고르는 방식입니다(각 행마다 고르는 것이 아닙니다). "사고 싶은 이유 없음"을 고르셨다면 2순위는 비워두셔도 됩니다.** — **객관식 그리드**: 행 = · 5분 완조리(간편함) · 외식 대비 가성비 · 국산 새우·숙주 등 재료 · 매실청의 새콤한 맛 · 향신료(고수 등) 부담 없음 · 사고 싶은 이유 없음 / 열 = 1순위 · 2순위. **설정: 문항 필수 ON(최소 1응답) · "각 행에 응답 필요" OFF · "열당 응답 1개로 제한" ON · 행 순서 셔플 ON.**
  - *기존 Q4 재사용 — H2 기제의 진술 버전. 계열 정의·집계법은 §3-11에 잠금. '외식 대비 가성비'는 가격 미노출 상태의 응답이므로 **기대 가성비**로 해석(§4).*
- **B3★ ⓢ** 반대로, 구매를 **가장 망설이게 하는 것** 하나는? — ① 맛이 상상이 안 된다 ② '진짜 팟타이 맛'이 아닐 것 같다 ③ 냉동식품 품질을 믿기 어렵다 ④ 가격이 걱정된다 ⑤ **양(1인분 300g)이 부족할 것 같다** ⑥ 팟타이 자체에 관심이 없다 ⑦ 망설여지는 점 없다
  - *의도: 저커밋 패턴(관심 48명 vs 1차 신호 8명)의 해석 문항. '양'은 게이트 A 갭(양·가격 12%)과의 정합으로 v1.2 추가 — 가격과 분리(묶으면 해석 오염).*
- **B4★** 성실 응답 확인 문항입니다. **'그렇다'(②)를 선택해 주세요** — ① 매우 그렇다 ② 그렇다 ③ 아니다 ④ 모르겠다. **셔플 OFF(순서 고정 필수).**

## 3. 분석 규칙 — 수집 전 사전 명시 (잠금)

1. **1차 분석 대상** = S1 ②~④(25–39) AND S4 ②~④(최근 1개월 구매 ≥1회) — 타깃 적합 부분집합.
2. **제외** = B4(주의력) 오답 응답 전체.
3. **대학생 세그먼트**(S2 ② 또는 S1 ①)는 별도 집계 — 타깃 데이터와 합산 금지. "확장 타깃 참고치"로만.
4. **호의 편향 검출** = F1 채널별 B1·C2 비교. 참고 기준: 지인 소개 채널이 익명 채널 대비 **B1 평균 +0.5점 이상 또는 C2 긍정(①+②) +15%p 이상**이면 지인 데이터에 편향 플래그 후 익명 채널 중심 해석. *(탐색용 관례치 — 유의성 검정 아님.)*
5. **판정 불변** = 어떤 결과도 게이트 B 행동 판정(H2)을 변경하지 않는다. B2에서 C 계열이 상위여도 "진술-행동 불일치 관측"으로 기록할 뿐, 행동이 우선한다.
6. **마감(조작화)** = 타깃 적합 30명 도달 후 **24시간 신규 응답 5건 미만이면 마감**, 타깃 적합 50명 도달 시 **즉시 마감**. 옵셔널 스토핑 금지 — 마감 후 일괄 분석.
7. **중복 응답** = 로그인 강제는 익명성 보호를 위해 쓰지 않는다. 제출 시각 패턴(단시간 연속 유사 응답)+B4로 필터, 잔여 위험은 소규모 탐색의 수용 한계로 명기.
8. **탐색 교차(일반화)** = {S3 가구형태 · S5 여행 · A1 팟타이 경험} × {B1 · C2}를 탐색 보고 — 각각 PT의 1·2인 가구 논리, 여행 향수 타깃, 시장 확장성(비경험자 반응)의 사후 확인.
9. **B2 응답 처리** = 같은 행을 1·2순위 모두에 찍은 응답은 1순위만 채택. "사고 싶은 이유 없음"을 1순위로 찍은 응답은 2순위 무효.
10. **E2 지위** = 보조 증거(인용 수준). 판정·비율 집계에 사용하지 않으며, 선택지 밖 기제의 탐지용.
11. **B2 계열 정의·집계법** = **A 계열 = {매실청의 새콤한 맛, 향신료 부담 없음} / C 계열 = {5분 완조리, 외식 대비 가성비(기대), 국산 새우·숙주 등 재료}**. 주지표 = **1순위 분포**, 보조지표 = 1·2순위 합산 언급 빈도(가중 없음). 두 지표가 갈리면 1순위 우선으로 해석.
12. **A2 집계 정의** = A 유병률 = (①+②)/전체 응답, B(접근성) = ③/전체. ⑤(단순 비선호)·⑥(잘 먹음)은 기피·장벽 어느 쪽에도 산입하지 않는다.
13. **C1⑤ 처리** = C1⑤("이런 맛을 안 찾는다") 응답자의 C2는 주 집계 분모에서 제외하고 "비수요층 전환"으로 별도 표기 — 문서 C 운영노트("⑤ 분모 제외 검토")의 규칙화.
14. **파일럿 제외** = 본 배포 시작 시각(기록해 둘 것) 이전의 모든 응답 = 파일럿, 본 분석에서 전량 제외.
15. **D1 비단조 처리** = "산다→안 산다"로 한 번만 꺾이지 않는 응답(예: 5,900 거절·6,900 수락)은 **원자료 보존 + 비단조 플래그**. 가격별 수락률 집계에는 그대로 포함(제외·보정하지 않음)하되 비단조 비율을 함께 보고한다. 비단조 비율이 **20% 초과** 시 GG 결과 전체를 "참고치"로 격하(탐색용 관례 컷). 저가 거절·고가 수락 패턴은 별도 카운트해 품질 추론 신호로 기록. B4 탈락과 독립 — 비단조만으로 응답자를 제외하지 않는다.
16. 모든 수치는 "진술 기준·편의 표본" 라벨을 달고 E §9.4에 기록.

## 4. 알려진 한계 (사전 명기)

- **A2→B2 프라이밍**: A2에서 '향신료' 선택지를 본 것이 B2 응답에 영향을 줄 수 있다. 그러나 A2의 unprimed 측정(컨셉 노출 전)이 우선순위가 높아 이 순서를 택했다 — 구조적 트레이드오프로 수용.
- **B2 '외식 대비 가성비' = 기대 가성비**: 가격 미노출 상태의 응답이므로 실가격 평가가 아니라 기대(냉동=저렴 추정, 편의 포함 가치, 단어 반응 등)를 잰다. 실가격 수용성은 D1의 관할로 엄격 구분. 기대의 내용물은 파일럿 인지 인터뷰(§1 키트 ③)로 확인.
- **GG 그리드 동시 노출·오름차순 제시**: 4개 가격이 한 화면에 보여 상호 앵커가 잔존하고, 오름차순 고정 제시로 인한 순서 앵커도 남는다. 다만 이는 전원에게 균일한 편향이라 상대 비교는 유지되며, 셔플의 오독발 비단조(§3-15 플래그 오염)보다 작은 비용으로 판단해 고정 제시를 택했다(표본 분할식 단일가 제시는 N 부족).
- **F1 prefill 가변**: 사전 채움 값을 응답자가 바꿀 수 있다 — S2(신분)와 교차해 명백한 불일치만 점검.
- **진술 ≠ 행동(총괄)**: 모든 결과는 진술 층위·편의 표본이다. 절대값이 아닌 상대 비교·방향으로만 읽는다.

## 5. 파일럿 프로토콜 (본 배포 전 필수 관문)

**목적** — 본 배포 전에 측정 도구 자체의 결함을 탐지한다. 파일럿이 검증하는 것은 응답 *내용*이 아니라 **설문지와 파이프라인**이다: 문항이 의도대로 읽히는가, 3분 안에 끝나는가, 응답이 §3 규칙으로 계산 가능한 형태로 기록되는가.

**조건(사전)**

| 항목 | 내용 |
|---|---|
| 대상·인원 | 지인 학회 단톡방 5~10명 (아는 사이 — 블라인드 불필요, 점검 목적 공개). **모바일 응답자 과반 포함**(그리드 오독 리스크의 주 무대가 좁은 화면) |
| 발송 문구 | §1 파일럿 발송 키트(피드백 3종 요청 포함) |
| 발송 전 상태 | 폼이 §2와 일치 + §6 체크리스트의 설정 항목(셔플·필수·안내문) 완료 |
| 데이터 지위 | 본 분석 전량 제외(§3-14) — 발송·회수 시각 기록 |

**절차(탐색 과정)**

1. **발송** — §1 키트 문구로 발송, 발송 시각 기록.
2. **회수** — 응답 5명 이상 + 피드백 3종(소요 시간·오해 문항·가성비 인지) 회수. 목표 48시간.
3. **점검 — 5개 탐색 항목**
   - (a) **소요 시간**: 자가 보고 수집(Forms는 소요 시간을 기록하지 않음) — 중앙값 기준.
   - (b) **문항 이해**: 피드백 ②에 더해 응답 데이터의 이상 패턴을 교차 — B4 오답, B2 같은 행 중복 선택, D1 비단조 발생률이 파일럿에서 비정상적으로 높으면 그 자체가 문항 결함 신호다. 이상 패턴은 기기(피드백 ④)와 교차해 모바일 특이 결함인지 확인한다.
   - (c) **이탈**: "하다 말았다" 여부를 단톡방에서 확인(Forms는 부분 응답을 저장하지 않아 자가 보고로만 가능).
   - (d) **인지 인터뷰**: '외식 대비 가성비'의 의미 회수 → §4 기대 가성비 해석에 반영. **합격 조건이 아니라 해석 자료** — 의미가 갈려도 불합격 사유가 아니다.
   - (e) **파이프라인 드라이런**: 응답 시트에서 §3 규칙이 실제로 계산되는지 파일럿 데이터로 시범 실행 — 1차 컷(규칙 1), B2 계열 집계(규칙 11), D1 곡선·비단조 플래그(규칙 15), prefill 기록(F1) 확인.
4. **판정** — 합격 기준(전부 충족): **소요 중앙값 ≤3분 · 문항 오해 0건 · 중도 이탈 0건 · 드라이런 통과.**
5. **분기**
   - **합격** → 본 배포 전환(아래).
   - **불합격** → 결함을 두 급으로 분류해 처리한다.
     - (가) **문구 수정**(의미 불변 — 오탈자·표현 다듬기): 즉시 수정 후 본 배포 가능, 재파일럿 불요.
     - (나) **측정 변경**(문항·선택지·규칙·순서 변경): 수정 → 설계서 버전 갱신·변경 이력 기록 → **재파일럿**(3~5명으로 축소 가능) → 재판정.
   - 수정 권한 경계: §3 잠금은 "본 수집 시작 전"까지다 — 파일럿 단계의 수정은 허용되나, 모든 수정을 이력에 남긴다(사전등록 정직성).

**본 배포 전환 조건(전부 충족 후 발송)** — ① 파일럿 합격 판정 ② 폼 최종본 고정(이후 무수정) ③ prefill 링크 3종 생성 ④ 본 배포 시작 시각 기록(§3-14 경계) ⑤ §3 잠금 선언.

**본조사 절차 개요(전환 후)** — ① 3채널 발송(§1) → ② 마감 조건 감시(§3-6, 중간 결과 엿보기 금지) → ③ 마감 → ④ 정리(파일럿 제외 → B4 제외 → 중복 필터 → 1차 컷) → ⑤ 집계(§3 규칙 순서대로) → ⑥ E §9.4 기록(파일럿 결과 요약 포함) → ⑦ 경품 추첨·발송, F2 연락처 폐기.
